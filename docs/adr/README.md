## Status Legend

| Status | Meaning |
|--------|---------|
| 📝 PROPOSED | Under review, not yet approved |
| ✅ APPROVED | Approved and ready for implementation |
| 🚧 IN PROGRESS | Currently being implemented |
| ✅ APPROVED & IMPLEMENTED | Approved and present in the codebase |
| ❌ REJECTED | Proposed but rejected |
| 🗄️ DEPRECATED | Previously approved but no longer relevant |

## Creating New ADRs

1. Use the next sequential four-digit number.
2. Name the file `NNNN-short-title.md`.
3. Start with status `📝 PROPOSED`.
4. Record the date, deciders, and decision scope.
5. Update this index when adding or changing an ADR.
